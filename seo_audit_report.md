## 1. Общий обзор видимости (SEO Executive Summary)

На основе анализа данных Google Search Console (GSC) и Google Analytics 4 (GA4) текущее состояние поисковой видимости и органического трафика toj-vitamin.tj можно охарактеризовать как **критически слабое, но имеющее высокий потенциал для быстрого роста**.

### Ключевые метрики за 30 дней:
*   **Органические клики (GSC):** Всего 7 кликов (все пришлись на главную страницу `/` со средней позицией 8.8 и CTR 14.0%).
*   **Показы в поиске (GSC):** Крайне низкий показатель — около 140-150 показов суммарно по всем страницам.
*   **Трафик (GA4):** 546 просмотров страниц (pageviews) на главной странице от 117 пользователей. 
*   **Локальное присутствие:** Сайт практически не ранжируется по коммерческим гео-запросам в Таджикистане (Душанбе, Худжанд и др.), хотя точечно собирает показы по брендовым запросам (например, GLS) и информационным статьям.

### Ключевые проблемы:
1.  **Отсутствие коммерческого трафика:** Единственный зафиксированный поисковый запрос — «аргинин gls» (4 показа, 0 кликов, позиция 46.3). Сайт не виден по базовым запросам «купить витамины в Душанбе», «витамин Д3 Таджикистан» и т.д.
2.  **Технический хаос с URL-адресами:** В GA4 и GSC наблюдается дублирование страниц с разными URL-структурами (кириллица, URL-encoded символы, пробелы в URL, разные варианты написания). Это дробит ссылочный вес и мешает индексации.
3.  **Мусорный трафик в аналитике:** Страница `/admin` занимает 2-е место по просмотрам (94 просмотра, 6 пользователей). Это внутренние переходы команды разработки/администраторов, которые искажают реальную маркетинговую картину в GA4.

## 3. Анализ расхождения трафика (Search vs Traffic)

Сравнительный анализ данных GSC (поиск) и GA4 (весь трафик) выявил критическую архитектурную проблему: **дублирование URL-адресов и рассинхронизацию каналов**.

### 1. Проблема "Зеркальных" URL-адресов:
В GA4 мы видим чистые, человекопонятные URL (ЧПУ):
*   `/product/кожа-волосы-ногти` (8 просмотров)
*   `/product/биотин-без-сахара` (6 просмотров)

В GSC те же самые товары индексируются по совершенно другим, перегруженным адресам с пробелами и спецсимволами:
*   `/product/%D0%BA%D0%BE%D0%B6%D0%B0-%D0%B2%D0%BE%D0%BB%D0%BE%D1%81%D1%8B-%D0%BD%D0%BE%D0%B3%D1%82%D0%B8-%D0%BA%D0%B0%D0%BF%D1%81.-400%D0%BC%D0%B3-%E2%84%9660-gls`
*   `/product/витамины для глаз капс.420мг №60 gls` *(URL содержит пробелы — критическая ошибка!)*

**Вывод:** На сайте отсутствует единый стандарт формирования URL. Робот Google пытается индексировать технические URL с длинными «хвостами», в то время как пользователи (вероятно, из соцсетей, Instagram или Telegram) переходят по сокращенным ЧПУ-адресам. Из-за этого страницы конкурируют друг с другом (канибализация), а поисковый вес размывается.

### 2. Внешний трафик без SEO-поддержки:
Страница `/product/формула-очищение` собрала 18 просмотров от 1 пользователя (вероятнее всего, прямой переход или реферальный трафик), но в GSC у нее **0 показов**. 
*   **Решение:** Если товар популярен в социальных сетях, его страницу необходимо срочно оптимизировать под SEO-запросы, чтобы собирать «теплый» поисковый трафик, который генерируется после прочтения постов в Instagram бренда.

## 5. Технический чек-лист для разработчиков

Для реализации маркетинговой стратегии разработчикам необходимо устранить критические технические ошибки, мешающие ранжированию сайта в Google.

### 1. Нормализация URL и устранение дублей (Критично)
*   [ ] **Запретить пробелы в URL:** Все пробелы в URL-адресах автоматически заменять на дефисы `-`. Привести все URL к нижнему регистру (lowercase).
*   [ ] **Настройка 301 редиректов:** Настроить постоянный 301-й редирект со сложных технических адресов (со спецсимволами, процентами `%D0...` и пробелами) на чистые ЧПУ-URL (например, с `/product/витамины для глаз...` на `/product/vitaminy-dlya-glaz-gls`).
*   [ ] **Канонизация (Canonical):** На всех страницах товаров прописать тег `<link rel="canonical" href="https://toj-vitamin.tj/product/clean-slug" />`, указывающий на эталонный ЧПУ-адрес.

### 2. Настройка аналитики GA4
*   [ ] **Фильтрация внутреннего трафика:** Исключить переходы разработчиков и контент-менеджеров на страницу `/admin` из общей статистики GA4. Настроить фильтр по IP-адресам команды.

### 3. Внедрение микроразметки Schema.org
*   [ ] **Разметка товаров (Product Schema):** Для всех страниц `/product/*` внедрить JSON-LD разметку. Google начнет показывать цены и наличие товара прямо в результатах поиска, что повысит CTR с 0% до 8-12%.
    ```json
    {
      "@context": "https://schema.org/",
      "@type": "Product",
      "name": "Мультивитамины GLS 12+9",
      "image": [
        "https://toj-vitamin.tj/images/product.jpg"
      ],
      "description": "Мультивитамины для взрослых в капсулах.",
      "sku": "GLS-12-9",
      "offers": {
        "@type": "Offer",
        "url": "https://toj-vitamin.tj/product/multivitaminy-12-9",
        "priceCurrency": "TJS",
        "price": "140",
        "availability": "https://schema.org/InStock"
      }
    }
    ```
*   [ ] **Разметка статей (Article Schema):** Для страниц `/journal/*` внедрить микроразметку статей для улучшения их отображения в Google Discover.

### 4. XML Sitemap и индексация
*   [ ] **Генерация XML-карты:** Настроить динамическую генерацию `sitemap.xml`. В карту должны попадать только канонические ЧПУ-страницы со статусом ответа 200 OK (исключить `/admin`, редиректы и дубли).
*   [ ] **Google Search Console:** Переотправить обновленный файл `sitemap.xml` в вебмастер Google для принудительного переобхода сайта роботом.
